# KAutoKey

**KAutoKey** is a lightweight automation tool for Windows that lets you run **keyboard and mouse actions** with hotkeys great for repetitive tasks, simple macros, and hands-free key pressing.

## Features
- **Keyboard auto key presser** (hold or repeat keys)
- **Mouse clicking support** (set actions to mouse buttons)
- **Multiple tasks/profiles** with their own settings
- **Hotkey controls** (toggle, or separate start/stop hotkeys)
- **Single-instance mode** (prevents multiple copies running)
- **Themes + modern UI**
- **Built-in updater** (update from inside the app)
