Profiles

Profiles keep setups separated.

When to use profiles

Use profiles for different apps, workflows, games, testing setups, or accessibility layouts. A profile can have its own tasks, remaps, variables, and presets.

Profile variables

Profile variables are shared across tasks in the active profile. Task variables are only for one task.
