Tasks

Tasks are saved action lists with their own hotkeys, loop behavior, rules, and variables.

What a task contains

  • Name: what the task is called.
  • Hotkey: the key/button that starts or toggles it.
  • Loop mode: how the action list repeats.
  • Actions: the actual steps the task runs.
  • Task Start Rules: optional checks before the task starts.
  • Task Variables: values the task can read or change.

Loop modes

Use run once for one-shot macros. Use until stopped for repeating assists. Use count or duration when you want the task to stop automatically.

Task Start Rules

Task Start Rules decide whether the whole task can start. They are different from Action Rules, which only control one action.
