Recorder

The recorder captures input and turns it into editable task actions.

Recording workflow

  1. Open Record.
  2. Start recording.
  3. Perform the input sequence.
  4. Stop recording.
  5. Review the generated actions.
  6. Adjust timing, repeats, or rules before using it.

Cleaning up recordings

Recorded actions may need cleanup. Delete accidental inputs, adjust waits, and simplify repeated sections when possible.
