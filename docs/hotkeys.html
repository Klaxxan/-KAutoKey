Hotkeys

Hotkeys start, stop, or toggle tasks.

Toggle vs separate start/stop

A toggle hotkey starts the task when it is stopped and stops it when it is running. Separate start/stop hotkeys let you choose different inputs for each behavior.

Device-specific hotkeys

If Windows exposes the input device separately, KAutoKey can limit a hotkey to a selected keyboard, numpad, mouse, or controller source. Use Detect Device when available so you do not have to guess from a list.
