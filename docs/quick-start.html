Quick Start

Create a basic task, add actions, and run it with a hotkey.

Create your first task

  1. Open the Tasks page.
  2. Click Create Task.
  3. Name the task something clear, like Jump Assist.
  4. Set a hotkey, such as F8.
  5. Add an Input action.
  6. Choose the key or mouse button to press.
  7. Press Start or use the hotkey.

Recommended first test

Make a task that taps Space once. Keep the loop mode set to run once. After that works, try repeat count, wait after, or until-stopped mode.
