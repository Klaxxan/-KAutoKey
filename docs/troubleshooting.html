Troubleshooting

Common issues and fixes.

Hotkey does not work

Check that the task is enabled, the hotkey is saved, and another app is not intercepting the same input.

Detection is slow

Use a smaller region. Full-screen color, image, or OCR scans can be slower.

Wrong device selected

Use Detect Device instead of guessing from Keyboard 1, Keyboard 2, etc.

Window rule cannot find my window

Refresh the window list or use the current active window picker again.

OCR text is wrong

Use a smaller region, increase contrast if possible, and avoid reading decorative or heavily stylized text.
