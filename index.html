Features

Everything you need for simple input assists.

Build actions in plain language, keep setups organized, and stay in control with hotkeys, profiles, remaps, and recording tools.

⌨

Task Builder

Create actions that tap, hold, type, scroll, move the mouse, and wait.

⚡

Hotkeys

Start and stop tasks with simple global hotkeys.

↔

Input Remapping

Make one key or mouse button act like another.

●

Macro Recorder

Record inputs and turn them into editable tasks.

◎

Profiles

Keep different setups organized and switch between them.

✦

Themes

Customize the look of the app while keeping the workflow clean.

How it works

Build a task in a few steps.

Create a task

Choose a name, set a hotkey, and decide whether the action list runs once or repeats.

Add actions

Tap or hold keys, click mouse buttons, scroll, move the cursor, type text, or add waits.

Start it

Run the task from the app or trigger it with your hotkey when you need it.
