Features

Built for everyday input workflows.

Start with a simple key press. Add profiles, remaps, recording, rules, variables, and detection only when you need them.

⌨

Task Builder

Create sequences with keyboard, mouse, text, timing, wait, scroll, and movement actions.

⚡

Hotkeys

Start and stop tasks with global hotkeys, separate start/stop keys, and device options.

↔

Remaps

Make one key or mouse button act like another inside organized profile setups.

●

Recorder

Record inputs and turn them into editable task actions.

◈

Rules & Variables

Let actions respond to windows, variables, timing, or other conditions.

◇

Detection

Use color, image, and text rules with window and region targeting.

How it works

Build tasks without writing code.

KAutoKey is based on readable actions and rules. Keep a task simple, or add logic when the workflow needs it.

01

Create a task

Name it, set a hotkey, and choose how the action list should run.

02

Add actions

Tap, hold, click, type, scroll, move, wait, read text, or update variables.

03

Add rules if needed

Run only when selected windows, regions, colors, images, text, or variables match.
